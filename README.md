## Assignment Overview
The Digital Detective assignment is an independent technical investigation into computer systems, terminal operations, operating systems, program execution, data representation, version control with Git & GitHub, and computer networking.

Each mission focuses on a specific foundational concept, and all missions are executed, documented, and committed in sequence to form a mini system report.

## How Each Mission is Completed
1. Each mission is tackled sequentially in its own dedicated directory.
2. Practical terminal commands, experiments, or scripts are run and verified on the local system.
3. Every mission folder contains a self-contained `README.md` following the standardized format (Task, Work Completed, Commands Used, Understanding, Difficulties, Resolution, Evidence, Commit Details).
4. Each completed mission is committed with a descriptive message and pushed to the remote GitHub repository before starting the next mission.
